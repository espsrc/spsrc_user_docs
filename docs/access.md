# Data Storage: Redundancy and Backup Policy

The platform’s project storage is provided by a high-performance Ceph distributed storage system configured with different levels of redundancy in order to provide fault tolerance and availability under normal operating conditions.

However, redundancy is not a substitute for backups.

Users must be aware that hardware failures beyond the fault-tolerance threshold, accidental deletion, data corruption, or software errors can result in permanent data loss. The platform does not perform automatic backups of project data and users are solely responsible for backing up all project-relevant data to external facilities.
